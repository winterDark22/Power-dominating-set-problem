# Power Dominating Set Problem

Heuristic approaches for solving the Power Dominating Set (PDS) problem.

## Notebooks

- `pds_greedy_heuristic.ipynb` — greedy heuristic implementation
- `pds_path_cover.ipynb` — path cover based approach

## Viewing the code

GitHub can't render these notebooks here because of file size. To view the code:

1. Download the `.ipynb` file (click the file → download button on the top right)
2. Open it in **VS Code** (with the Jupyter extension) or **Jupyter Notebook**

That's it.
